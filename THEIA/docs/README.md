# THEIA Documentation

This directory contains project-level documentation about source extraction, implementation status, limitations, and reproducibility.

## Extraction Status

See `EXTRACTION_STATUS.md` for the current extraction record.

The repository preserves original notebooks, Python exports, organized source directories, and an extracted custom model prototype.

## Documentation Principles

- Distinguish completed work from planned work.
- Record implementation limitations.
- Preserve original research outputs.
- Do not claim checkpoint compatibility without verification.
- Do not claim APT detection performance without suitable labels and held-out evaluation.
- Keep deployment instructions separate from architecture claims.
